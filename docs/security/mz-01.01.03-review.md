# MZ-01.01.03: results of the branch scans

Scan 68cceffe of the release branch (4752a90, SAST, SCA, KICS, containers and secrets) found 64 results: 1 critical, 31 high, 22 medium, 9 low and 1 info (62 SAST, 1 KICS, 1 SCA). This Checkmarx One project's only earlier scan is fe2eb036 of 18 October, so 34 were marked New against it; that does not mean this branch added them. None of the 64 flagged lines changed on this branch (each checked with `git blame` against main c3e7d58). 35 match a result judged before, by file and query, in [MZ-01.01.00's review](mz-01.01.00-not-exploitable.md) or [MZ-01.01.02's](mz-01.01.02-review.md). The other 29 were each checked against the code: 3 are fixed in ea687f2, 26 are not exploitable, for the reason given. Scan 1e267f36 of d99a5cd (the release's code before those fixes) found the same 64. RESCAN Line numbers are those of 4752a90. Back to [status](../status.md).

Checkmarx One refuses SAST state changes from the connector's account (it lacks SAST triage rights), so the results judged not exploitable wait for an administrator to mark them, as those before them do.

## Fixed in ea687f2

| Severity | Where | Result | What changed |
| --- | --- | --- | --- |
| High | `src/mailer.js:99` | Cleartext Transmission | With **Secure connection from the start** off, the mail library upgraded with STARTTLS only when the server offered it: someone on the path who removed the offer would have received the SMTP user name and password in clear. A sign-in now requires TLS (`requireTLS` whenever a sign-in is sent); a relay without a sign-in works as before. A server that offers no STARTTLS gets its own **How to fix it**. test/outbound-tls.test.js and test/troubleshoot.test.js check both. |
| Medium | `src/automation-config.js:223` | Regular Expression Denial of Service | Automation's focus patterns (`payments-*`) became regular expressions with `.*` for each star, which backtrack: `*a*a*a*a*a*a*a*ab` against a 60-character project name held the server for about 35 s. Patterns are now matched by a two-pointer wildcard matcher, linear in the name and pattern, with no regular expression. test/automation-page.test.js times the case that used to stall. |
| Medium | `src/labs-routes.js:67` | Error Message Containing Sensitive Information | A failed fetch's raw message was kept for the consolidated view, unexpected server errors included. Only Checkmarx One's own answers (a 4xx or 5xx status) are kept now; anything else reads "Something went wrong on the server. The details are in its log.", as the fetch itself already says. |

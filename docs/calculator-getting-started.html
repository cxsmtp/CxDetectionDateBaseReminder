Getting started

Cx Credits Calculator

Work out the Checkmarx One credits a customer needs (triage & remediation, and Fusion) in minutes, and hand them a report and slides. It runs on your own computer, in your browser.

Have Node.js 20+?

Run the calculator file on its own:

node cx-credits-calculator.mjs

2 Start it

Windows

  1. Right-click the zip, choose Extract All, then open the folder.
  2. Double-click Start Cx Credits Calculator.cmd (one program: Cx Credits Calculator.exe; if Windows protected your PC: More info, Run anyway).
  3. The calculator opens in your browser. Keep the black window open while you work.

macOS

  1. Double-click the zip to unzip it, then open the folder.
  2. First time only: right-click Start Cx Credits Calculator.command (one program: Cx Credits Calculator), Open, then Open again.
  3. The calculator opens in your browser. Keep the Terminal window open while you work.

The browser did not open? Go to http://127.0.0.1:47317. To stop the calculator, close its window.

3 Work out the credits

  1. Type Your organisation: it goes on every report.
  2. Paste a Checkmarx One API key (one that may read projects and scans) and press Connect. The read starts by itself and the figures fill in as projects arrive.
  3. Optional: paste a GitHub, GitLab or Bitbucket token beside it and press Add: every repository it can see is counted for Fusion.
  4. Check the credits: try the severities, the period and New findings counted (%). The highest Fusion estimate counts; Use this instead picks another.
  5. Generate projection report for an HTML report the customer can play with, then Download PDF summary for the slides.

4 Your data stays with you

Customers and reports are saved in cx-credits-calculator-data.json in the calculator's folder and loaded from it next time. Copy the folder to keep your work or move it to another computer.

The API key and git tokens are never saved. The calculator talks only to your Checkmarx One and your git host; everything else stays on your computer.

5 Good to know

  • Port 47317 is in use: the calculator is already open in another window. Close it and start again.
  • Company network that inspects HTTPS: set NODE_EXTRA_CA_CERTS to your company's root certificate file before starting.
  • No API key? The Triage & remediation tab also takes the two exports from Checkmarx One → Analytics.
  • Counting code from git uses git when it is installed, otherwise the platform's API.

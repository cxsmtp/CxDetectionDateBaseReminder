Scan initiators

Checkmarx records the person who ran a scan as a username, which is not always an email address. These rules turn it into one; the dashboard shows what each project resolved to.

Mail template

The message body is yours to decide. Values are inserted with {{name}} and HTML-escaped; {{{name}}} inserts raw HTML. Repeat a list with {{#projects}}…{{/projects}}, and show a block only when something is empty with {{^projects}}…{{/projects}}.

Automation

Checks on a timer and mails the moment a finding crosses one of your age thresholds. Each finding is reported once per threshold, so a daily sweep does not re-send the same thing every day.

Troubleshooting log

What this server records about its own use: which features are used and how fast, where errors happen, and where numbers disagree (for example Checkmarx One answering differently on two reads, or a request refused for lack of credits) — with recommended fixes. Send it to whoever maintains Mission Zero when something goes wrong.

These logs do not capture any sensitive information at all: no names, email addresses, passwords, keys, tokens, hosts, URLs, findings or code. Only feature names, counts, timings, status codes and error types, and project ids replaced by one-way codes.
